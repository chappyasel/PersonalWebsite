# Issue tracker: GitHub

Issues and PRDs for this repo live as GitHub issues. Use the `gh` CLI for all
operations and infer `chappyasel/PersonalWebsite` from the repository remote.

## Conventions

- Create issues with `gh issue create`.
- Read issues and their discussion with `gh issue view <number> --comments`.
- Add and remove labels with `gh issue edit`.
- Close completed issues with `gh issue close` and a concise completion note.

## Pull requests as a triage surface

**PRs as a request surface: no.**

## When a skill says "publish to the issue tracker"

Create a GitHub issue in this repository.

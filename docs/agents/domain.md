# Domain Docs

This repository uses a multi-context domain map.

Before exploring a domain, read `CONTEXT-MAP.md`, then the relevant linked
`CONTEXT.md`. Read system-wide ADRs under the repository's `docs/adr/`
directory and context-specific ADRs under that context's own `docs/adr/`
directory. ADR numbering is independent within each directory.

Use the glossary's preferred terms in issue titles, specs, tests, and code.
If proposed work conflicts with an ADR, surface the conflict rather than
silently overriding the recorded decision.

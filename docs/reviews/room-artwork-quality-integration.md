# Sharper artwork integration

All six non-About shelves now use smoother SVG contours and sharper embedded photos, covers and labels in light/dark and desktop/phone variants. The artwork is integrated on `feat/illustrated-room` in `f709d3a`, following the approved foliage integration at `27c0155`. The capture utilities and builder reports are preserved in the surrounding commits.

The [builder report](room-artwork-quality-RESULT.md) describes capture provenance, encoding and exact sizes. The [independent integration evidence](room-artwork-quality-evidence/root-integration.json) records all 24 placement, camera, owner-order, Books and clock invariants, plus 528 comparisons against fresh scene masks. The largest conservative Manhattan residual is 2.885 CSS pixels. All 48 integrated full/shelf drawing files match the reviewed bytes, and the production preview serves the exact 24 reviewed full SVGs.

About, the shelf-only polygons, boot animation and plant wind retain their existing implementation. This integration changes no runtime source files. It preserves the empty shelf, top-left to bottom-right reveal, final placement, delayed cards/navigation and automatic 2D-to-3D handoff.

`pnpm check:room-artwork` now runs the fresh-mask geometry check after verifying sources, frozen inputs and generated bytes. It remains part of `verify:artifacts` and needs no browser. The new `check:room-artwork-quality` command derives display scale from the current shared camera/frame helpers and reads committed masks, so it has no dependency on the temporary review baseline.

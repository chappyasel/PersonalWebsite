# Overlays and homepage release

This release includes the shared branch's overlay coordination, video viewer,
image gestures, scene time controls, homepage cards, mobile chrome, search
routing, icons, social cards, and Sticker Camera inspection changes.

## Artwork source review

Ten artwork dependencies changed. The frame wrappers in Grabbable, ModelProp,
PhysicsSceneProvider, WavingGolfFlag, GolfExperience, and unitActivity change
animation scheduling without changing resting geometry. PropApproach registers
inspection overlays and keeps its existing rest transforms. UnitTalks places
the Sticker Camera inside an inspection wrapper with the same rest position
and yaw as before.

The talkGalleryLayout and talkPhotoSetups changes move the monitor arm plate,
elbow, and drop behind the interview print's backing. Photo dimensions, shelf
poses, and registration anchors stay the same. The approved 2D drawings retain
their captured monitor-arm detail; this receipt does not claim a new capture
or identical support geometry. Approved SVGs, raster details, and capture
inputs remain intact.

The packaging fingerprints record this review. The existing homepage OG image
remains unchanged; its source freshness is advisory in the release workflow.

## Discoveries

Overlay, zoom, and presentation refinements add no meaningful qualifying
action under Field Notes quality-bar test 2. The CR orb retains its existing
`ripple-effect` discovery. Expanding its speed effect adds no separate award.

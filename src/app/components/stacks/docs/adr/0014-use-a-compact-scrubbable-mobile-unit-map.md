# Restore the direct mobile Rail and retain scrubbing

The mobile Rail shows seven permanently visible Unit glyphs. Each glyph is a
direct navigation button with an accessible Unit name. Sliding horizontally
across the row previews Units through the Travel-Synced Placard and commits
World travel on release.

Brief haptic ticks may reinforce transitions on supporting devices but are
never required feedback, because web vibration support is not universal.
Vertical movement must remain native. The Rail cedes touch while the Peek
Sheet is in Ambient Reading.

This restores one-tap access and keeps every destination visible. The compact
Unit Map hid the destinations behind an extra tap, and its unlabeled notches
did not explain the scrub gesture. Scrubbing remains useful as a faster option,
but it no longer replaces the direct buttons.

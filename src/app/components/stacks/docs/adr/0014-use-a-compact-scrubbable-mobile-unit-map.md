# Use a compact scrubbable mobile Unit Map

The mobile Rail will rest as a compact Unit Map showing the active Unit's name
and seven tactile notches rather than seven permanently exposed unlabeled
icons. Tapping it expands a fully labeled map. Sliding across its notches
previews Units through the Travel-Synced Placard and commits World travel on
release.

The control must communicate scrubbing through visible compression,
resistance, and a decisive snap. Brief haptic ticks may reinforce transitions
on supporting devices but are never required feedback, because web vibration
support is not universal. The Unit Map cedes touch while the Peek Sheet is in
Ambient Reading.

This preserves a visible map of the seven-Unit Traverse while returning more
of the narrow viewport to the World. It is chosen over a permanent icon row,
which is crowded and cryptic, and hidden menu navigation, which erases the
scene's spatial model.

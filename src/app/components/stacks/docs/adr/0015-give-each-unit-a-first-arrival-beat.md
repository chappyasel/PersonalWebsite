# Give each Unit a first-arrival beat

Each Unit will have one restrained, authored Arrival Beat tied to its own
Identity Props, creatures, or motivated light. It plays on that Unit's first
arrival during a session. Revisits use only the normal camera settle.

This makes arrival feel acknowledged and gives each Unit a distinct character
without replaying a theme-park effect on every visit. A single generic
transition would preserve consistency but lose the Units' identities, while
ambient motion alone would not provide a clear arrival payoff.
